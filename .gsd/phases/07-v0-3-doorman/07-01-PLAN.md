# S01: Toolchain and theme

**Milestone:** M007
**Slice:** S01

**Goal:** Upgrade toolchain to material3 1.5.0-beta02 (Kotlin 2.x + Compose compiler plugin), rebrand to Doorman (label, LED-dot adaptive icon, copy), and ship DoormanTheme with LaneColors, Manrope/DM Mono typography and shared core-ui components with a dark/light preview gallery.
**Demo:** Launcher shows Doorman with LED-dot icon; preview gallery renders every shared component in dark and light

## Must-Haves

- ./gradlew assembleDebug and ./gradlew check pass on the new toolchain; exact versions recorded in the task summary
- applicationId remains com.usagecontrol; app_name = Doorman; mipmap-anydpi-v26/ic_launcher.xml with monochrome layer
- No hard-coded "Usage Control" strings remain in Kotlin sources
- DoormanTheme (MaterialExpressiveTheme, static dark/light, dynamic colour off by default) used in MainActivity; LocalLaneColors exposes six lanes
- ComponentGallery previews compile for all shared components in dark and light; JVM unit test asserts lane tokens differ between schemes

## Proof Level

- This slice proves: Build + unit tests + compiled previews; on-device launcher check is UAT

## Integration Closure

S03 consumes DoormanTheme, LocalLaneColors and the shared components from core-ui.
