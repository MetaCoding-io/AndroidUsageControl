# S03: Shell and Now — UAT

**Milestone:** M007
**Written:** 2026-11-04T06:40:49.256Z

## UAT Type
- UAT mode: runtime-executable

## Preconditions
Debug APK installed on a device, with notification listener access granted.

## Steps
1. Launch the app. Expected: the bottom bar shows exactly Now, Apps and Modes. Tap the gear: Settings opens.
2. Run `adb shell cmd notification post -S bigtext -t Test tag1 "hello"`. Expected: the row appears in Now with an icon and a lane dot, and the hero count goes up.
3. Search for "hello". Expected: the list filters to the matching row.
4. Swipe the row right. Expected: an Undo snackbar appears. Tap Undo within 10 s. Expected: the row returns and the system notification is still present.
5. Swipe right again and wait 10 s. Expected: the system notification is cancelled, and logcat NotificationCapture logs "cancelled".
6. Post another notification and swipe it left. Expected: a TimePicker opens. Pick a time and confirm. Expected: logcat shows "snoozed" and the notification disappears from the shade.
7. Tap a row. Expected: the original app opens. If its intent is missing, the app's launch activity opens instead and a snackbar says "Original no longer available".

## Edge cases
- With listener access revoked, archive, snooze and open show an error snackbar and the app does not crash.
- Dismissed notifications appear under Recently dismissed for 1 hour.
