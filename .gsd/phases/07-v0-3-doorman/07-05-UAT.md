**Milestone:** M007

## UAT Type
- UAT mode: runtime-executable

## Operational Readiness
- **Health signal**: clean builds pass the KSP Hilt guard; the app cold-launches with no AndroidRuntime errors in logcat.
- **Failure signal**: the build fails with "produced no Hilt_ class for X", or logcat shows NoClassDefFoundError Hilt_*.
- **Recovery**: re-run a clean build. If the failure persists, bump the KSP/Hilt versions.
- **Monitoring gaps**: none at runtime. The guard runs only at build time.

## Preconditions
Emulator Medium_Phone_API_36.1 running; debug APK installed.

## Steps
1. Run `./gradlew clean :app:assembleDebug` 3 times. Expected: each run succeeds and Hilt_UsageMonitorService is in the KSP output.
2. Launch the app. Expected: no NoClassDefFoundError in logcat.
3. Tap the gear, then the back arrow. Expected: the Now tab is shown.
4. Run `adb shell cmd uimode night yes` and relaunch. Expected: Ink background and light bar icons. Reset with `cmd uimode night no`; expected: Paper background and dark icons.

## Edge cases
- System back from Settings also returns to Now.
