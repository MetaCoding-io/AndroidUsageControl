<objective>
Add degraded-mode warning banners to the three main feature screens (Notifications, Screen Time, Controls) for users who skipped permissions during onboarding. Each banner explains which permission is missing and what feature is affected. Banners update reactively on ON_RESUME when the permission state changes.

Purpose: Users who skip permissions during onboarding must understand why features are unavailable. Without clear messaging, they will perceive the app as broken rather than permission-gated. This completes the PERM-05 requirement.
Output: Shared DegradedPermissionBanner in core-ui, plus banner integration in all three affected feature ViewModels and screens.
</objective>

1. **Add `DegradedPermissionBanner` to `CommonComponents.kt`** in `core/core-ui/src/main/java/com/usagecontrol/core/ui/component/`:

   Append this composable at the end of the file (after `UsageBar`):

   ```kotlin
   @Composable
   fun DegradedPermissionBanner(
       message: String,
       modifier: Modifier = Modifier,
   ) {
       Card(
           modifier = modifier
               .fillMaxWidth()
               .padding(horizontal = 16.dp, vertical = 8.dp),
           colors = CardDefaults.cardColors(
               containerColor = MaterialTheme.colorScheme.errorContainer,
           ),
       ) {
           Text(
               text = message,
               modifier = Modifier.padding(16.dp),
               style = MaterialTheme.typography.bodyMedium,
               color = MaterialTheme.colorScheme.onErrorContainer,
           )
       }
   }
   ```

   Design decisions:
   - Uses `errorContainer` / `onErrorContainer` colors from Material3 theme for warning appearance without adding custom colors.
   - Accepts `message: String` only -- feature-specific text lives in the feature module, not core-ui.
   - No dismiss button -- the banner should persist as long as the permission is missing (dismissing would hide a real problem).
   - No `onOpenSettings` callback -- keeping it simple for Phase 2. Users can grant permissions from system Settings directly. A "Grant now" action can be added in a future polish pass.

   Add the required import for `Icon` at the top of the file if not already present -- but this composable only uses `Card`, `Text`, `CardDefaults`, `MaterialTheme`, `Modifier`, and `dp`, all of which are already imported in the file.
